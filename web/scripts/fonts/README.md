# Product-film typography

JetBrains Mono Regular and Bold are bundled only for the offline canvas renderer.
They are not additional website runtime downloads. All added video text uses
these fonts; the actual app screenshot pixels remain unchanged.

Source: https://github.com/JetBrains/JetBrainsMono
Pinned upstream commit: `19371302b95d218af43299bce79ddbddd0bc364d`
Original paths: `fonts/ttf/JetBrainsMono-Regular.ttf`,
`fonts/ttf/JetBrainsMono-Bold.ttf` and `OFL.txt`.
