# Snap 9.7.1

- Auto Clips uses the editor's neutral theme and shared glass material, dropdowns, switches and sliders. Dark and light modes follow the editor palette.
- Headings and step navigation scroll with the content. Only the action footer stays visible. Range and clip boundaries accept timecodes, and short sources no longer show an irrelevant ten-minute shortcut.
- Created clips have a direct edit action. Opening a clip saves the original project first. The editor keeps an Original timeline button and a timeline selector for the generated clips; switching saves edits and restores each timeline's playhead.
- Analysis progress remains animated when the engine does not report a live percentage. Downloads retain percentage progress. Source preview media releases when leaving the source step.
- Release publishing now waits for GitHub Actions to finish publishing the installer, then queries assets by release ID. It no longer creates a competing draft or relies on the draft's REST tag URL. Existing releases and assets are preserved.

Validation includes the source graph, TypeScript, editor tests, source/clip navigation and playhead restoration tests, and PowerShell 5.1 publishing simulations with no network writes. Visual checks use a development fixture; actual GitHub publication still requires the maintainer's authenticated terminal when the workspace cannot access its credentials.

The standalone executable is unsigned. Installer updater signatures are generated by GitHub Actions and are separate from Windows Authenticode signing.
